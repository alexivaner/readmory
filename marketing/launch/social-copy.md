## YouTube

**Title:** I built Readmory to remember what I read on my Kobo

**Description:**
I wanted a way to revisit my books and the ideas I’d underlined. So I built Readmory: a local-first reading workspace for Kobo, KOReader and Kobalt.

Getting started: connect your Kobo by USB, enable storage mode, choose the Kobo folder or saved files, review the preview, and import. Readmory leaves the Kobo files untouched. Folder-picker behavior can vary, so individual source files are supported too.

In this walkthrough I use my cleaned reading library to browse books, explore recorded reading history, and find old highlights. The import demonstration uses a labeled synthetic fixture.

Try the public beta: https://alexivaner.github.io/readmory/
Code and documentation: https://github.com/alexivaner/readmory

No account is required. Imports and reading data stay in your browser. Optional Open Library cover lookup sends book metadata when enabled. Browser storage can be cleared, so keep a backup. Available history depends on what your reader recorded; reconstructed time is labeled.

I’d love to hear which part of your reading you wish was easier to revisit. Please don’t post private databases or backups in public issues.

## Reddit developer showcase

**Title:** I made Readmory, an open-source local-first workspace for Kobo reading history and highlights

Hi everyone, I’m the developer of Readmory. I wanted an easier way to revisit my reading outside the device, so I made a browser app that imports Kobo databases, KOReader statistics/sidecars and Kobalt SQLite records.

It has a cover library, searchable highlights, a separate view for personal notes, reading statistics and a calendar with the books behind each day. The attached demo uses my cleaned library. Any import-fixture scene is labeled synthetic.

The core doesn’t need an account. Imported data stays in the browser. Optional cover lookup sends ISBN/title-author information to Open Library, and is off by default. Browser storage can be cleared, so download backups. Reading history varies by source and firmware; estimates and missing time stay labeled.

App: https://alexivaner.github.io/readmory/
Source (MIT): https://github.com/alexivaner/readmory

This is a public beta and a personal project. I’d appreciate feedback on the import flow and which reading insights are actually useful. Please use synthetic examples when reporting issues publicly, rather than attaching your database or backup.
